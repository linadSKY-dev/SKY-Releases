# SKY-Releases

Официальный каталог установщиков приложений SKY для Windows.

Здесь публикуются только готовые файлы для установки. Исходный код и служебные файлы в этот репозиторий не добавляются.

## Как скачать приложение

1. Выберите нужную программу в списке ниже.
2. Откройте её страницу релиза.
3. В разделе **Assets** скачайте файл с окончанием `-Setup.exe`.
4. Запустите установщик. Если Windows запросит права администратора — подтвердите их.

## Поддержка

Если приложение не запускается или есть предложение по улучшению, создайте обращение во вкладке [Issues](https://github.com/linadSKY-dev/SKY-Releases/issues).

## Для будущих выпусков

При добавлении новой программы или версии:

1. Откройте **Releases** → **Draft a new release**.
2. Создайте понятный тег, например `sky-info-v1.1.0`.
3. Прикрепите только готовый установщик `*-Setup.exe`.
4. В описании кратко перечислите изменения.
5. Обновите таблицу **Программы** выше: название, назначение, версию и ссылку на релиз.
